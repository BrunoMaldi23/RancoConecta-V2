# Cleanup Review

Buscar:

- archivos temporales;
- backups;
- código muerto;
- imports sin uso;
- duplicaciones;
- scripts de parche puntual;
- documentación obsoleta;
- carpetas vacías;
- pantallas abandonadas.

No eliminar automáticamente si hay duda.

Clasificar cada candidato:

- mantener;
- eliminar;
- revisar antes de decidir.

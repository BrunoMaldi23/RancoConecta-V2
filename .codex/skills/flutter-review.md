# Flutter Review

Revisar:

- arquitectura Flutter;
- separación `data`, `application`, `presentation`;
- widgets;
- estado;
- responsive;
- performance;
- imports;
- código muerto;
- reutilización de componentes existentes.

No aprobar cambios que:

- pongan Supabase directo en widgets;
- dupliquen lógica de providers o repositories;
- introduzcan UI no responsive;
- agreguen archivos sin una responsabilidad clara.

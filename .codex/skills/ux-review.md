# UX Review

Revisar:

- jerarquía visual;
- espacios;
- responsive;
- formularios;
- experiencia del usuario final;
- claridad de acciones;
- consistencia por vertical.

El flujo debe mantenerse:

1. Descubrir.
2. Conocer prestador.
3. Contactar o reservar.
4. Confirmar.

No convertir pantallas en flujos transaccionales de ecommerce.

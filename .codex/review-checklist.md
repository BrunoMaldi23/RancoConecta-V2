# Review Checklist

## Código

- [ ] `flutter analyze --no-pub` limpio.
- [ ] Formato aplicado a archivos modificados.
- [ ] UTF-8 correcto.
- [ ] Sin archivos basura.
- [ ] Sin duplicación innecesaria.
- [ ] Sin código muerto introducido.

## Producto

- [ ] Respeta el modelo Ranco Conecta.
- [ ] No agrega ecommerce.
- [ ] No agrega POS.
- [ ] No agrega ERP.
- [ ] No agrega delivery, carrito ni checkout.
- [ ] Respeta Basic / Pro mediante capabilities.
- [ ] Es responsive.

## Base de datos

- [ ] Migración segura.
- [ ] RLS revisado.
- [ ] Ownership validado.
- [ ] Sin pérdida de datos.
- [ ] Índices y FK revisados.

## Entrega

- [ ] Cambios resumidos.
- [ ] Tests o validaciones reportadas.
- [ ] Pendientes declarados.
- [ ] `git diff --check` limpio.
